<section>
    <h2>¿Qué es la Virtualización?</h2>
    <p>
        Tecnología que permite ejecutar múltiples sistemas operativos y aplicaciones
        sobre un mismo hardware físico.
    </p>
</section>

<section>

```
<section>
    <h2>Solución Estratificada</h2>
    <p>Los problemas en TIC pueden resolverse mediante diferentes capas.</p>

    <ol>
        <li>Hardware</li>
        <li>Virtualización</li>
        <li>Sistema Operativo</li>
        <li>Aplicaciones</li>
        <li>Usuario Final</li>
    </ol>

    <p>↓ Profundizar</p>
</section>

<section>
    <h2>Nivel Hardware</h2>
    <p>
        Corresponde a los componentes físicos:
        CPU, memoria, almacenamiento y red.
    </p>
</section>

<section>
    <h2>Nivel Virtualización</h2>
    <p>
        Abstrae los recursos físicos para crear máquinas virtuales.
    </p>
</section>
```

</section>

<section>

```
<section>
    <h2>Virtualización por Interpretación Pura</h2>

    <p>
        Cada instrucción del sistema invitado es interpretada individualmente.
    </p>

    <p>↓ Ver características</p>
</section>

<section>
    <h2>Características</h2>

    <ul>
        <li>Alta compatibilidad.</li>
        <li>Implementación sencilla.</li>
        <li>Menor rendimiento.</li>
    </ul>
</section>

<section>
    <h2>Casos de Uso</h2>

    <ul>
        <li>Investigación.</li>
        <li>Sistemas antiguos.</li>
        <li>Pruebas de software.</li>
    </ul>
</section>

<section>
    <h2>Ejemplos</h2>

    <ul>
        <li>Bochs</li>
        <li>QEMU (modo emulación)</li>
    </ul>
</section>
```

</section>

<section>

```
<section>
    <h2>Virtualización por Recompilación Dinámica</h2>

    <p>
        Traduce bloques completos de instrucciones en tiempo real.
    </p>

    <p>↓ Ver profundidad</p>
</section>

<section>
    <h2>Características</h2>

    <ul>
        <li>Mayor velocidad.</li>
        <li>Optimización automática.</li>
        <li>Menor sobrecarga.</li>
    </ul>
</section>

<section>
    <h2>Casos de Uso</h2>

    <ul>
        <li>Emuladores.</li>
        <li>Compatibilidad entre arquitecturas.</li>
        <li>Pruebas multiplataforma.</li>
    </ul>
</section>

<section>
    <h2>Ejemplos</h2>

    <ul>
        <li>QEMU TCG</li>
        <li>Dolphin Emulator</li>
        <li>PPSSPP</li>
    </ul>
</section>
```

</section>

<section>

```
<section>
    <h2>Hipervisión (Bare Metal)</h2>

    <p>
        El hipervisor se ejecuta directamente sobre el hardware.
    </p>

    <p>↓ Ver profundidad</p>
</section>

<section>
    <h2>Características</h2>

    <ul>
        <li>Máximo rendimiento.</li>
        <li>Alta seguridad.</li>
        <li>Escalabilidad.</li>
    </ul>
</section>

<section>
    <h2>Casos de Uso</h2>

    <ul>
        <li>Centros de datos.</li>
        <li>Nube privada.</li>
        <li>Infraestructura empresarial.</li>
    </ul>
</section>

<section>
    <h2>Ejemplos</h2>

    <ul>
        <li>VMware ESXi</li>
        <li>Microsoft Hyper-V</li>
        <li>Xen</li>
    </ul>
</section>
```

</section>
